# 职航 · 大学生校招与官方直聘助手

聚焦大学生校园招聘与实习求职的一体化工作台（React + Vite + Tailwind CSS + Express + Node.js 原生 SQLite，**同时支持 GitHub Pages 纯静态本地隐私运行**）。

## 核心功能与数据口径说明

1. **官方企业校招检索、数据分级与地区筛选（覆盖 199 家正规企业）**
   - 收录大厂科技、高成长 AI/具身初创、半导体芯片、新能源车企、专精特新科创、国央企、金融机构、外企名企 **16 大职能方向**。
   - **分级透明**：严格区分通过北森 / 大易 HotJob 等公开 ATS 接口直抓的 **「官网原岗 · 直达详情」**（直接跳转岗位详情页），以及人工整理的 **「官网入口 · 方向参考」**（薪资统一标为「以官网为准」，跳转企业官网或官网检索页自行核验），不经手任何三方中介与培训引流。
   - 支持全国标准化城市群多选、招聘通道切换、**临近截止 / 最新发布排序**，以及「官方名企入口墙」（带工商主体与天眼查核验入口）。
2. **招聘信息更新中心 & 批量导入**
   - 内置网申截止时间自动巡检（过期自动下线 `closed`、10 天内临近截止预警 `closing_soon`）。
   - 支持一键全量同步、配置合规公开 RSS/Atom / JSON Feed / JSON-LD 订阅源（本地后端或 Actions 运行），以及通过文本/CSV/JSON **批量去重导入**学校就业群或内推清单。
3. **校招简历工坊与 A4 PDF 导出**
   - 内置 **4 套校招专属模板**（极简技术单栏 ATS 友好风、现代双栏紧凑风、国央企/金融稳重风、产品运营亮色风）。
   - 支持多版本简历管理、派生副本、模块显隐排序、STAR 句式快捷提示、A4 单页实时填充度监测，以及高精度矢量 PDF 打印导出。
4. **投递信息管理看板**
   - 支持 **6 阶段看板视图 (Kanban) + 列表视图 (Table)** 流转，关联投递简历版本、内推码、笔面试倒计时、面经复盘，以及一键导出 UTF-8 `.csv` 表格备份。
